# Character reference — ART DIRECTION ONLY

Fourteen-pose turnaround/action sheets for the four fighters, supplied by the
project owner.

## These are NOT game assets

They exist so that a human or an agent can *look* at them while authoring the
procedural characters. They are never imported by `src/`, never bundled by Vite,
and never sampled at runtime. Every pixel the game draws is generated by our own
code.

If you find yourself writing `import ... from '../../reference/...'`, stop — that
is the one thing this directory must never be used for. `npm run build:check`
fails the build if anything under `src/` references this path.

## Contents

Each fighter directory holds the same 14 poses:

| File | Use |
| --- | --- |
| `01-neutral-front` | proportions, silhouette, front-facing palette |
| `02-neutral-left-profile` | depth, limb thickness, chest/back curvature |
| `03-neutral-back` | back-of-costume detail, hair from behind |
| `04-neutral-right-profile` | asymmetry check |
| `05-neutral-three-quarter` | primary modelling view |
| `06-fighting-guard` | canonical fighting stance |
| `07-high-hand-ready-stance` | guard variant, arm read |
| `08-defensive-block` | block pose |
| `09-crouching-guard` | crouch proportions |
| `10-standing-straight-punch` | punch extension, hip rotation |
| `11-lunging-straight-punch` | weight transfer, lunge reach |
| `12-airborne-knee-tuck` | jump/air pose, tuck volume |
| `13-front-kick` | kick extension, supporting leg |
| `14-high-side-kick` | high kick, hip opening |

## Fighters

- **vera** — grappler. Copper braided mohawk, burnt-orange quilted vest,
  plum crop top, charcoal compression shorts, white hand wraps, wrestling boots.
- **davi** — capoeira. Locs tied with blue, gold sleeveless cropped hoodie,
  cream *abadá* with blue side stripe, blue cord belt and wraps, barefoot.
- **mali** — muay thai. Long segmented braid with red ties, teal sports bra with
  gold trim, black satin muay thai shorts with red/gold flares, red hand and
  ankle wraps, barefoot.
- **kai** — karate. Black topknot with orange headband, navy sleeveless wrap gi,
  wide orange obi, charcoal calf-length pants, white hand wraps, orange ankle
  wraps, navy shoes.
